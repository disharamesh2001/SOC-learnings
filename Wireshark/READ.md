# Wireshark

## Overview

This learning path focused on mastering Wireshark for packet analysis, network troubleshooting, and security investigations. Through a series of practical exercises, I explored packet capture fundamentals, packet filtering techniques, protocol analysis, and traffic investigation workflows commonly used by SOC analysts and incident responders.

The exercises provided hands-on experience in analyzing network communications, identifying suspicious activity, and extracting valuable information from packet captures (PCAPs).

## Objectives

* Understand the fundamentals of packet analysis
* Navigate the Wireshark interface efficiently
* Capture and inspect network traffic
* Apply display and capture filters

* Perform network traffic analysis using PCAP files
* Develop investigative workflows for security incidents

## Challenges Faced

### Understanding Large Packet Captures

Network captures often contain thousands of packets, making it difficult to quickly identify relevant traffic.

### Identifying Important Protocols

Determining which protocols were significant to the investigation required understanding how different network services communicate.

### Building Effective Filters

Creating accurate filters to isolate relevant traffic was challenging during the initial stages of analysis.

### Correlating Network Activity

Investigations required correlating multiple packets and conversations to understand the complete communication flow.

## How I Overcame Them

### Applying Structured Analysis Techniques

Started by identifying key hosts, protocols, and communication patterns before examining individual packets.

### Using Display Filters

Leveraged Wireshark display filters to reduce noise and focus on relevant traffic.

### Analyzing Protocol Hierarchies

Used protocol statistics and packet details to better understand network communications.

### Following Communication Streams

Tracked conversations between hosts to reconstruct network activity and identify suspicious behavior.

## Key Takeaways

* Packet captures provide valuable visibility into network activity.
* Wireshark enables detailed inspection of network communications at multiple protocol layers.
* Effective filtering significantly improves investigation efficiency.
* Understanding protocol behavior is essential for detecting suspicious activity.
* Structured traffic analysis helps identify anomalies, investigate incidents, and support threat-hunting activities.
* Network analysis is a critical skill for SOC analysts and incident responders.
