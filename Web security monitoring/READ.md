# Web Security Monitoring

## Overview

This learning path focused on monitoring, detecting, and investigating threats targeting web applications and web infrastructure. Through a series of SOC-oriented exercises, I explored web security fundamentals, attack detection techniques, web shell identification, and Distributed Denial-of-Service (DDoS) attack analysis.

The labs emphasized how security analysts leverage logs, network traffic, and system artifacts to identify malicious activity affecting web services and applications.

## Objectives

* Understand core web security concepts
* Learn common web application attack techniques
* Analyze web logs and network traffic for signs of compromise
* Detect web-based attacks and malicious activity
* Identify indicators associated with web shells
* Understand DDoS attack methodologies and detection strategies
* Develop investigative workflows for web security incidents

## Domain

**Web Security | Security Operations Center (SOC) | Threat Detection | Incident Response**

Web applications are among the most targeted assets in modern environments. Security analysts monitor web infrastructure to detect attacks, investigate suspicious activity, and protect business-critical services from compromise.

## Challenges Faced

### Understanding Diverse Web Attack Techniques

Web attacks can take many forms, including exploitation attempts, web shells, credential attacks, and denial-of-service campaigns. Each attack type leaves different indicators and requires a different investigative approach.

### Investigating Incomplete Evidence

Attack indicators may appear across multiple sources such as logs, traffic captures, and system artifacts, requiring investigators to piece together the full picture.

## How I Overcame Them

### Learning Attack Signatures and Behaviors

Focused on understanding how common web attacks are executed and the indicators they typically leave behind.

### Analyzing Request Patterns

Reviewed traffic patterns, request frequency, response behavior, and unusual URLs to identify suspicious activity.

## Key Takeaways

* Web applications are frequent targets for attackers and require continuous monitoring.
* Logs provide valuable evidence for identifying suspicious activity and investigating incidents.
* Effective web attack detection depends on understanding both normal and malicious web behavior.
* Web shells often leave detectable traces within logs, file systems, and network traffic.
* DDoS attacks can be identified through abnormal traffic patterns and resource consumption.
* Correlating multiple data sources improves investigation accuracy and threat detection capabilities.
* Structured investigation workflows are essential for effective web security monitoring.
