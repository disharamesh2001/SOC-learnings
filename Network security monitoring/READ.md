# Network Security Monitoring

## Overview

This learning path focused on monitoring and analyzing network activity to identify signs of malicious behavior and security incidents. Through a series of practical exercises, I explored network security fundamentals, asset discovery techniques, intrusion detection concepts, data exfiltration methods, and Man-in-the-Middle (MITM) attack detection.

The exercises emphasized the role of network visibility in detecting adversarial activity and provided hands-on experience with techniques commonly used by SOC analysts, threat hunters, and network defenders.

## Objectives

* Understand core network security principles
* Learn how attackers discover network assets
* Identify indicators of network reconnaissance activity
* Detect potential data exfiltration attempts
* Understand Man-in-the-Middle attack techniques
* Learn the fundamentals of Intrusion Detection Systems (IDS)
* Develop network monitoring and investigation skills

## Domain

## Challenges Faced

### Recognizing Malicious Activity Within Normal Traffic

Network environments generate large amounts of legitimate traffic, making it challenging to distinguish suspicious behavior from routine communications.

### Identifying Indicators Across Multiple Attack Stages

Many attacks leave subtle traces across different parts of the network, requiring correlation of multiple indicators before conclusions can be drawn.

## How I Overcame Them

### Learning Common Attack Patterns

Focused on understanding how adversaries perform reconnaissance, establish communication channels, and move data across networks.

### Analyzing Behavioral Indicators

Examined traffic patterns, communication frequency, destination hosts, and protocol usage rather than relying solely on individual events.

## Key Takeaways

* Network monitoring provides critical visibility into potential security threats.
* Reconnaissance activities often leave identifiable traces within network traffic.
* Data exfiltration attempts can be detected by analyzing communication patterns and unusual network behavior.
* Man-in-the-Middle attacks may introduce observable anomalies in network communications.
* Intrusion Detection Systems play an important role in identifying suspicious activity.
* Effective security monitoring requires both technical analysis and contextual understanding of network behavior.
* Network traffic serves as a valuable source of evidence during security investigations and incident response activities.
