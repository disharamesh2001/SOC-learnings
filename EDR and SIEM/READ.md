# EDR & SIEM Fundamentals

## Overview

This learning path introduced the core concepts of Endpoint Detection and Response (EDR) and Security Information and Event Management (SIEM). The exercises focused on understanding how modern security teams monitor endpoints, collect and analyze security events, detect threats, and investigate suspicious activity across enterprise environments.

The rooms provided foundational knowledge of security monitoring workflows commonly used by Security Operations Center (SOC) analysts and incident responders.

## Objectives

* Understand the role of EDR in endpoint security
* Learn how SIEM platforms collect and analyze security data
* Explore event monitoring and threat detection workflows
* Understand alert generation and investigation processes
* Gain familiarity with SOC operations and security monitoring concepts

## Domain

**Security Operations Center (SOC) | Threat Detection | Security Monitoring | Incident Response**

EDR and SIEM solutions form the backbone of modern SOC operations. Security teams use these technologies to detect malicious activity, investigate alerts, and respond to security incidents across organizational environments.

## Challenges Faced

### Interpreting Security Events

Security platforms generate large amounts of event data, and distinguishing meaningful security events from normal activity required careful analysis.

### Understanding Alert Context

Alerts often represent only a portion of an investigation. Understanding how individual events fit into a larger security incident required broader context.

## How I Overcame Them

### Analyzing Events Methodically

Reviewed security events individually before examining how they related to other activities within the environment.

### Building Context Around Alerts

Learned to treat alerts as starting points for investigations rather than final conclusions, helping develop a more investigative mindset.

## Key Takeaways

* EDR provides visibility into endpoint activity and helps identify suspicious behavior on individual systems.
* SIEM platforms centralize and correlate security events from multiple data sources.
* Effective threat detection relies on both endpoint telemetry and centralized event analysis.
* Security alerts require investigation and validation before conclusions can be drawn.
* EDR and SIEM technologies work together to improve detection, investigation, and response capabilities.
* Understanding security monitoring workflows is fundamental for SOC analysts and incident responders.
