# Splunk Basics

## Overview

This room introduced Splunk, a widely used Security Information and Event Management (SIEM) platform used by security teams to collect, search, analyze, and visualize security data. The exercises focused on understanding how Splunk processes logs, performs searches, and supports security investigations through data analysis.

Through hands-on activities, I learned how to navigate Splunk, execute search queries, filter results, and extract meaningful insights from security events.

## Objectives

* Understand the purpose and architecture of Splunk
* Learn how data is indexed and searched
* Navigate the Splunk interface efficiently
* Perform searches using Splunk Processing Language (SPL)
* Filter and analyze log data
* Investigate security events using log analysis techniques

## Domain

**Security Operations Center (SOC) | SIEM | Log Analysis | Threat Detection**

Splunk is commonly used by SOC analysts, threat hunters, and incident responders to monitor security events, investigate alerts, and identify suspicious activity across enterprise environments.

## Challenges Faced

### Understanding Log Structure

Security logs contain numerous fields and attributes, making it challenging to determine which information was most relevant during investigations.

### Building Effective Search Queries

Constructing queries that returned meaningful results required understanding Splunk's search syntax and filtering capabilities.

### Identifying Relevant Events

Large datasets often contain significant amounts of normal activity, making it necessary to distinguish important security events from background noise.

### Interpreting Search Results

Understanding how different events related to each other required careful analysis and contextual awareness.

## How I Overcame Them

### Exploring Event Fields Systematically

Reviewed event details and field values to better understand how information is organized within Splunk.

### Practicing Query Refinement

Started with broad searches and gradually refined them using filters and search operators to narrow investigation results.

### Focusing on Investigation Objectives

Defined clear goals before searching, helping prioritize relevant data and avoid unnecessary information.

### Correlating Events for Context

Examined related events and patterns to better understand the overall activity being investigated.

## Key Takeaways

* Splunk enables efficient collection, searching, and analysis of large volumes of security data.
* Effective log analysis depends on understanding event structures and search techniques.
* SPL queries help analysts quickly identify relevant events during investigations.
* Log analysis plays a critical role in threat detection, incident response, and security monitoring.
* Structured searches and filtering techniques significantly improve investigation efficiency.
* SIEM platforms provide valuable visibility into organizational security events.
